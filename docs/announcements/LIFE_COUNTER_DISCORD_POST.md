# Discord Announcement - Life Counter

```
NEW: Mobile Life Counter + Match Reporting!

Track your Sorcery games and update ELO automatically!

HOW TO USE:
→ Visit sorcererssummit.com/life-counter on your phone
→ Tap +/− to adjust life & threshold counters
→ When game ends (0 life), tap "Report Match"
→ Fill in opponent, deck URL, and who went first
→ Submit as winner or loser
→ Opponent confirms → ELO updates!

FEATURES:
• Auto-saves your game state
• Fullscreen mode
• Recent opponent search
• 48hr auto-confirm if no response
• Dual-sided display (hand phone to opponent!)

REQUIREMENTS:
• Login with Discord/Google to report matches
• Deck URL required (curiosa.io/decks/...)

Try it now: sorcererssummit.com/life-counter

Questions? Ask in #help!
```
